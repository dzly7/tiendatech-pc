# Tiendatech PC - TechStore PC

Sitio web oficial de **TechStore PC**: especialistas en venta de computadoras de escritorio armadas, componentes individuales de hardware y ensambles a medida.

## Estructura del Proyecto

- `index.html`: Estructura semántica en HTML5 con secciones de inicio, catálogo de productos/servicios y contacto.
- `logo.jpg`: Imagen del logotipo de TechStore PC.

## Visualización

Para ver el proyecto en tu navegador:
1. Abre el archivo `index.html` con doble clic o arrástralo a cualquier navegador web (Chrome, Edge, Firefox, etc.).
